# Launch materials

What CURB published, kept as a record. The numbers are as of each launch; the current ones are on
curb.guide/about and in CLAUDE.md (for example, 815,000 matched tickets became 1.05 million on 13 Oct 2026).

- `product-hunt/`: the Product Hunt launch, 7 Oct 2026. `LISTING.md` is the listing as submitted,
  `REPLIES.md` the facts for answering comments, `gallery/` and `thumbnail-240.png` the images,
  `share-card/` the share image before and after that launch.
- `social-2026-09/`: the 28 Sep 2026 posts about the iOS 1.0.2 update (Instagram story, LinkedIn
  carousel, X thread), with the text of each post.
